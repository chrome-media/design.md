## 4. 🎯 Рекомендуемые цели для Яндекс.Метрики

Проверить, что из этого уже настроено, после подключения к счётчику.

### Конверсионные (главные)

1. **Отправка формы заявки** — JS-событие на сабмит каждой формы (главная, цены,
   акции, балконы).
2. **Расчёт в калькуляторе** — клик по «Рассчитать» на `/kalkulyator-okon/`
   (микроцель → видно, сколько считают, но не оставляют контакт).
3. **Клик по номеру телефона** — `tel:` ссылки; оба номера раздельно.
4. **Клик по email** — `mailto:0808896@mail.ru`.
5. **Клик по WhatsApp/мессенджеру** — если кнопка есть.
6. **Заказ обратного звонка** — если стоит виджет.

### Вспомогательные (поведение)

7. Просмотр страницы `/aktsii/` (интерес к скидкам).
8. Просмотр «Контактов» / клик по карте (намерение приехать).
9. Глубокий визит (≥3 страниц или ≥2 мин) — прокси-вовлечённость.

### Воронка

Составная цель: **калькулятор → форма → заявка** — покажет, где отваливаются
посетители.

## 5. Что проверить и посчитать после подключения к API

- **Техаудит счётчика:** один счётчик или дубли; включён ли Вебвизор, карта
  кликов, фильтрация роботов; стоит ли код на всех страницах.
- **Источники + CPL:** Директ vs SEO vs карты/2ГИС vs прямые — что даёт заявки и
  звонки, где дорогой лид.
- **Конверсия и цели:** есть ли цели вообще, % визита в заявку, эффективность
  калькулятора.
- **Поведение:** отказы, глубина, мобайл vs десктоп, проблемные страницы
  входа/выхода.
- **Вебмастер:** индексация, поисковые запросы, ошибки, региональность
  (Новосибирск).

## 6. Как подключить реальные данные

1. Получить OAuth-токен на <https://oauth.yandex.ru> (аккаунт с доступом к
   счётчику, право `metrika:read`; для Вебмастера — доступ к его API).
2. Передать токен в среду (env-переменная `YANDEX_METRIKA_TOKEN` /
   `YANDEX_WEBMASTER_TOKEN` или `.env`).
3. Открыть в network allowlist окружения хосты:
   - `api-metrika.yandex.net`
   - `api.webmaster.yandex.net`
   - `okna-veka54.ru`
   - `oauth.yandex.ru`

После этого — выгрузка отчётов через Stat API (`/stat/v1/data`) и Management API
(`/management/v1/counters`, `/management/v1/counter/<id>/goals`).
