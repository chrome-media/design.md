# Fallout: Cascadia Rising — дизайн-пакет мобильной RPG

Проработанная концепция мобильного RPG-продолжения Fallout 2: исследование первоисточников,
сюжет, системы персонажа и геймплея, адаптация под мобильные устройства.

## Как читать

Документы выстроены по принципу «от источника к продукту»:
сначала фиксируем, *что делает Fallout — Fallout'ом* (01), затем проектируем
сюжет, не противоречащий канону (02), затем системы, дающие ту самую свободу
отыгрыша (03–04), и в конце адаптируем всё под телефон (05).

## Ключевые дизайн-решения (TL;DR)

- **Сеттинг:** Тихоокеанский Северо-Запад («Каскадия»: Орегон — Сиэтл), 2253 год —
  через 12 лет после Fallout 2 и до событий New Vegas, чтобы не конфликтовать с каноном.
- **Герой:** потомок Избранного из Нью-Арройо — прямое продолжение линии Vault Dweller → Chosen One.
- **Антагонист:** остатки Анклава, эвакуировавшиеся из Наварро на север, + климатический проект «Чинук».
- **Системы:** классические S.P.E.C.I.A.L. 1–10, 2 трейта, 16 навыков (3 tag-навыка), перк каждые 3 уровня.
- **Бой:** пошаговый, на очках действия (AP), прицельные выстрелы по частям тела — как в оригинале.
- **Отыгрыш:** каждый ключевой квест решается минимум тремя путями: бой / скрытность+взлом / речь+наука.
- **Мобильность:** сессии 5–15 минут, автосейв на каждом переходе, ландшафтная ориентация, premium-модель без pay-to-win.
