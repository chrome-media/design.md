# SEO-структура сайта batbaza.ru

## 1. Принцип сегментации спроса

Спрос на автомобильные аккумуляторы делится по нескольким **независимым осям**.
Каждая ось — это и ветка структуры каталога, и кластер семантики. Грамотная
структура = пересечение этих осей в виде отдельных посадочных страниц под
коммерчески значимые срезы.

| Ось | Значения |
|:----|:---------|
| **Тип техники / применение** | легковые, грузовые, мото, спецтехника, коммерческий транспорт, лодочные/тяговые, для дизельных двигателей |
| **Технология** | AGM, EFB, GEL (гелевые), кальциевые Ca/Ca, малосурьмянистые, для Start-Stop |
| **Ёмкость, Ач** | до 45, 45–55, 55–60, 60–65, 65–75, 75–100, 100–200, 200+ |
| **Полярность** | прямая (1), обратная (0) |
| **Пусковой ток, EN (А)** | диапазоны (например 500–600, 600–700, 700+) |
| **Типоразмер / стандарт** | Европа, Азия (JIS), L1–L6, корпус |
| **Напряжение** | 6В, 12В, 24В |
| **Бренд** | FORSE, MORATTI, DOMINATOR, WPR, TORNADO, FB, UNO, «Русская Звезда», «Курский аккумулятор» и пр. |
| **Марка/модель авто** | Lada, Toyota, Kia, Hyundai, VW, Renault, … → модель → двигатель |

## 3. Типы страниц и их SEO-роль

| Тип | URL-паттерн | Главный интент | Роль |
|:----|:------------|:---------------|:-----|
| Главная | `/` | ВЧ «купить аккумулятор» | Брендовый + общий ВЧ-трафик |
| Каталог-хаб | `/akkumulyatory/` | «автомобильные аккумуляторы» | Распределяет вес по категориям |
| Категория (тип техники) | `/akkumulyatory/{тип}/` | «аккумулятор для {тип}» | Основной коммерческий трафик |
| Подкатегория (технология) | `/akkumulyatory/{tech}/` | «{tech} аккумулятор» | СЧ-трафик по технологиям |
| SEO-тег (характеристика) | `/akkumulyatory/{param}/` | «аккумулятор {param}» | НЧ/СЧ-хвосты с высокой конверсией |
| Связка (тип+param) | см. §4 | низкочастотные точные | Максимальная конверсия |
| Бренд | `/brand/{brand}/` | «аккумулятор {бренд}» | Брендовый спрос |
| АКБ для марки авто | `/akkumulyator-dlya/{marka}/` | «аккумулятор для {авто}» | Огромный пласт НЧ-спроса |
| Карточка товара | `/akkumulyatory/{...}/{tovar}` | модель + артикул | Точные транзакционные |
| Инфостатья | `/blog/{slug}/` | «как выбрать/зарядить…» | Верх воронки, охват, E-E-A-T |

## 4. Коммерческие связки (пересечения осей)

Самый недооценённый источник конверсионного НЧ-трафика — страницы на пересечении
двух признаков. Создавать под ходовые комбинации (валидируя частотность):

- `…/legkovye/agm/` — AGM аккумуляторы для легковых
- `…/legkovye/60ah/` — аккумулятор 60 Ач для легковых
- `…/agm/obratnaya-polyarnost/` — AGM обратной полярности
- `…/emkost-60ah/obratnaya-polyarnost/` — 60 Ач обратной полярности
- `…/gruzovye/190ah/` — грузовой аккумулятор 190 Ач
- `…/moto/gelevye/` — гелевые мотоаккумуляторы

Правило: страница-связка создаётся, только если (а) есть спрос (Wordstat > 0) и
(б) под неё есть ≥ 3–5 товаров. Иначе — `noindex` или фильтр без отдельного URL,
чтобы не плодить тонкие страницы.

## 5. Информационный раздел (блог) — кластеры

Под информационные запросы (верх воронки + E-E-A-T для YMYL-доверия):

- **Выбор:** как выбрать аккумулятор; какой аккумулятор лучше; AGM или EFB; чем отличается AGM от обычного; рейтинг аккумуляторов {год}.
- **Параметры:** что такое полярность; как определить полярность; как узнать ёмкость; что такое пусковой ток; типоразмеры АКБ.
- **Эксплуатация:** как зарядить аккумулятор; как проверить АКБ; как продлить срок службы; почему разряжается; как хранить зимой; обслуживание.
- **Подбор:** как подобрать аккумулятор по марке авто; можно ли ставить большую ёмкость.
- **Утилизация/обмен:** сдать старый аккумулятор; trade-in; сколько стоит старый АКБ.

Каждая статья ссылается на релевантную коммерческую категорию (перелинковка
«статья → категория»).

## 6. Перелинковка

- **Хлебные крошки** на всех страницах каталога: `Главная › Каталог › {Категория} › {Товар}`.
- **Категория → связки/теги:** блок «Популярные подборки» (60 Ач, AGM, обратная полярность…).
- **Карточка товара → бренд / категория / «АКБ для {марка авто}»** (если применимо).
- **Блог → коммерческая категория** (контекстные ссылки внутри статей).
- **Главная → топ-категории** (тип техники + технологии) в первом экране.
- Избегать ссылок на отфильтрованные URL с GET-параметрами, ведущие на `noindex`.

## 7. Шаблоны мета-тегов

Использовать переменные `{Категория}`, `{Бренд}`, `{Марка}`, `{Город}`, `{минЦена}`.

**Категория (тип техники):**
- `Title`: `Аккумуляторы для {категория} — купить АКБ в {Город} | Batbaza.ru`
- `Description`: `Аккумуляторы для {категория} в наличии. ✓ Гарантия ✓ Обмен старого АКБ ✓ Доставка по {Город}. Цены от {минЦена} ₽. Подбор по параметрам.`
- `H1`: `Аккумуляторы для {категория}`

**Технология:**
- `Title`: `{Технология} аккумуляторы — купить в {Город} | Batbaza.ru`
- `H1`: `Аккумуляторы {Технология}`

**SEO-тег (ёмкость/полярность):**
- `Title`: `Аккумулятор {param} — купить в {Город} | Batbaza.ru`

**Бренд:**
- `Title`: `Аккумуляторы {Бренд} — официальный магазин, цены | Batbaza.ru`
- `H1`: `Аккумуляторы {Бренд}`

**АКБ для марки авто:**
- `Title`: `Аккумулятор для {Марка} — подбор и цены | Batbaza.ru`
- `H1`: `Аккумулятор для {Марка}`

**Карточка товара:**
- `Title`: `Аккумулятор {Бренд} {Модель} {Ёмкость} Ач {Полярность} — купить, цена`

## 8. Структурированные данные (Schema.org)

- `Product` + `Offer` (цена, наличие, гарантия) на карточках.
- `AggregateRating` / `Review` при наличии отзывов.
- `BreadcrumbList` на всех страницах каталога.
- `ItemList` на категориях.
- `FAQPage` на категориях и статьях (блок вопрос-ответ).
- `Organization` + `LocalBusiness` для региональных поддоменов (адрес, телефон, часы).
