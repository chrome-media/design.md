# Семантическое ядро — batbaza.ru

## Как читать документ

- Запросы сгруппированы в **кластеры**, каждый кластер привязан к одной
  посадочной странице из `01-struktura-sajta.md`.
- **Тир частотности** (оценочно, требует подтверждения по Wordstat):
  **ВЧ** — высокочастотные (тысячи+ показов/мес), **СЧ** — средние,
  **НЧ** — низкочастотные «хвосты».
- **Интент:** `C` — коммерческий (купить), `T` — транзакционный (точная модель/параметр),
  `I` — информационный.

> ⚠️ Реальные числа частот не проставлены — нужен Wordstat/Keys.so по регионам.
> Процедура догрузки — в конце файла (§«Сбор частотностей»).

## Сбор частотностей (для оператора)

1. Выгрузить все запросы из этого файла в одну колонку (csv/xlsx).
2. Прогнать через **Яндекс.Wordstat** (регион «Москва» + регионы поддоменов:
   Белгород, Старый Оскол и т.д.) — снять `"!запрос"` (точную) и широкую частоту.
   Альтернативы / ускорение: **Keys.so**, **Bukvarix**, **Key Collector**.
3. Дополнить ядро НЧ-хвостами через подсказки и правую колонку Wordstat,
   а также из отчётов поиска **Яндекс.Метрики** и **Search Console / Вебмастера**
   (реальные запросы, по которым сайт уже показывается).
4. Удалить нулёвки и нерелевантные; разметить интент; финализировать привязку
   кластер → URL.
5. Проверить **каннибализацию**: один запрос — одна посадочная страница.
