# SEO-структура и семантическое ядро — batbaza.ru

Проект: интернет-магазин автомобильных аккумуляторов **batbaza.ru**
(торговый дом Курского аккумуляторного завода, бренды FORSE, MORATTI, DOMINATOR,
WPR, TORNADO, FB, UNO, «Русская Звезда», «Курский аккумулятор» и др.).

Дата сборки: 2026-06-18.

## Методология

1. **Анализ ниши и текущего сайта.** Определён профиль: продажа АКБ для легковых,
   грузовых авто, мото, спецтехники. Зафиксирована текущая структура URL и
   собственные торговые марки.
2. **Сегментация спроса.** Спрос на АКБ разбивается по независимым осям:
   тип техники → технология → характеристики (ёмкость, полярность, ток,
   типоразмер) → бренд → марка авто. Каждая ось = ветка структуры и кластер СЯ.
3. **Проектирование структуры.** Под каждый коммерчески значимый срез спроса
   проектируется отдельная посадочная страница (категория / подкатегория /
   SEO-тег / бренд-страница / страница «АКБ для {марка авто}»).
4. **Сбор семантики.** Кластеры запросов сгруппированы по интенту и привязаны к
   страницам. Указаны частотные тиры (ВЧ/СЧ/НЧ).

## ⚠️ Важно про частотности

Точные частоты (Wordstat / Keys.so) **в этом наборе не проставлены** — для них
нужен доступ к Яндекс.Wordstat, Keys.so, Bukvarix или Google Keyword Planner с
привязкой к региону. В файле `02-semanticheskoe-yadro.md` запросы размечены
тирами **ВЧ / СЧ / НЧ** (оценочно) и описана процедура, как догрузить реальные
числа. Это сделано осознанно: проставлять выдуманные цифры частот нельзя.

## Следующий шаг (для оператора)

1. Прогнать список запросов из `02-...` через Wordstat/Keys.so по нужным регионам
   (Москва + регионы поддоменов: Белгород, Старый Оскол и т.д.).
2. Уточнить кластеры по реальной частоте, отсечь нулёвки, добавить НЧ-хвосты.
3. Внедрять структуру по приоритетам из `03-tekhnicheskij-audit.md`.
